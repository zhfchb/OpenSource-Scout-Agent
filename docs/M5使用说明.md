# M5：自动发现与候选管理（预期使用说明）

版本：2.2｜2026-10-29｜待实现。当前项目尚无本页所述画像、发现或候选按钮；本页用于后续实现与验收，不是已可运行教程。

## 1. 配置与首次发现

所有者在浏览器登录，进入计划新增的“机会/画像与发现设置”。默认语言 Java/Python，偏好 good first issue/help wanted；调整活跃度、规模代理条件和仓库排除。标签偏好不保证贡献资格，star 不代表代码复杂度。

保存后点击“立即发现”。规则发现只需可用 GitHub 只读 API，不要求模型；匿名请求可能更易限流。页面显示排队、轮次预算、扫描数量、过滤原因与未完成范围。不因没有结果自动扩大查询或反复调用模型。

## 2. 定时与可选评估

定时初始关闭。明确启用后默认每天 UTC 02:00（北京时间 10:00），可调整每日整点或关闭。云端进程检查到期，浏览器关闭不影响已启用调度。停机错过的轮次跳过，不恢复后连跑；重启未完成轮次标中断，可手动发起新轮次。

模型评估默认关闭。开启前显示可能持续计费，并受每轮/每日调用和 Token 上限约束；只评价少量 Issue 摘要，不整仓分析。未配置/预算不足显示 NOT_RUN，不确定用量为 UNKNOWN，不包装成模型推荐。取消一轮不关闭下次定时，关闭定时不等于忽略候选。

## 3. 阅读和管理候选

列表展示仓库、Issue、来源、匹配理由、疑点、最后检查时间和规则/模型来源。候选仅表示可能值得贡献，可能已过期、有人认领或已有未发现修复。不完整扫描会标部分完成。

收藏保留关注；忽略后不再推荐，重扫不解除。恢复须到“已忽略”明确点“重新启用”。排除仓库过滤新推荐；解除排除不自动恢复已忽略项，仍需重新匹配/复核。已创建分析不会随忽略/排除自动取消，须到任务页单独取消。

## 4. 人工选择和复核

点“进入分析”只创建人工选择请求，经单槽先读当前 Issue/仓库及有限关联修复/PR。关闭或可确认已修复时停止付费分析；开放关联 PR 或信息未知时展示来源/风险并等待确认。未检出关联不代表排除所有重复修复，确认过期或内容改变须重新检查。

之后使用 [M1 分析流程](M1使用说明.md)、[M2 计划确认与审核下载](M2使用说明.md)。规则发现无需模型，深入分析需要有效模型配置/预算；不完整时提示补齐，不自动开始。选择不能代替计划确认；补丁 UNVERIFIED，目标编译/测试 NOT_RUN，验证与提交在系统外完成。

## 5. 失败、恢复与限制

限流显示冷却/未知原因并释放槽，不无限重试；预算/分页耗尽显示缺口。新画像用于后续轮次，当前禁用付费/排除/忽略即时收紧。中断可能已付费，UNKNOWN 评估不自动重发；明确重新评估仍受限额。

恢复备份后定时默认关闭，恢复当日发现模型评估禁用；核对旧水位/偏好后重新启用。候选/画像均私有，不自动进入游客报告。细则见 [M5 设计](M5自动发现设计.md)，验收见 [验收标准](验收与发布标准.md)。当前能力待实现，真实 GitHub/付费评估验收均未执行。
