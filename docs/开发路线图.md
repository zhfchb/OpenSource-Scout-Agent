# OpenSource Scout Agent 开发路线图

版本：2.0｜2026-10-29｜待实施。当前范围以PRD v2.0为准，旧M0—M5不再作为执行清单。

## 1. 原则

所有功能经浏览器操作，应用部署在云端；2核2GB为实测目标。固定流程、单实例、单活动任务，先提供有用分析与待验证补丁。第三方代码不执行；没有运行的测试不得标通过。

每阶段交付可运行增量、实际验证、限制和下一步。没有实测不得写阶段完成；不为尚未需要的平台能力增加常驻组件。

## 2. M0：轻量Web工程与部署基线

- 检查实际目录、AGENTS.md、Git及Node环境，保护已有文件。
- Vue 3/TS/Vite前端，Node/TS/Fastify后端；单进程提供构建后的前端和API。
- SQLite及版本化SQL迁移、健康检查、结构化日志、配置与密钥引用。
- 管理员登录/会话/变更请求保护，任务列表和设置页面骨架。
- 运行时输入schema、限额配置、默认禁止目标代码执行。
- 锁定实际兼容版本；部署脚本/systemd、HTTPS代理示例、备份说明。

验收：前后端构建和类型检查、服务启动、健康/迁移、未登录拒绝管理操作、日志脱敏；不运行Vite或tsc常驻服务。记录可用环境的空闲内存；未取得2GB云环境时标记容量验证未执行。

## 3. M1：手动Issue分析

- 仓库/Issue链接校验，仓库有限Issue列表与选择。
- GitHub只读适配、Commit固定的有界源码文本获取。
- SQLite任务表与进程内单执行器、重复提交保护、轮询状态。
- 单模型配置、结构化分析、调用超时与调用数/Token预留。
- 中断标记和手动步骤重试、取消与attempt检查。

验收：真实公开Issue产生可核查报告，明确数据缺口；夹具验证分页限制、错误、预算、重复触发、重启中断和取消迟到结果。记录来源与实际用量；无凭据时不伪造真实调用。

## 4. M2：计划确认与待验证补丁

- 展示修改计划，确认绑定Commit和hash。
- 单次生成统一Diff和PR文案；范围/路径/格式/大小检查。
- 超范围、敏感路径或新增依赖要求修订确认；不自动修复循环。
- 私有下载、人工审核状态、手工PR链接/结果记录。

验收：至少一个真实分析可经确认生成审核包；未确认不能生成，计划变化不能复用旧确认；危险路径被拒绝。补丁统一UNVERIFIED，项目编译/测试明确NOT_RUN，人工PR状态标MANUAL。

## 5. M3：公开报告与2GB部署验证

- 白名单发布快照、预览确认、公开列表与详情、撤回。
- HTTPS、登录和下载权限、Markdown安全渲染、敏感内容测试。
- 日志/缓存/制品上限、备份与恢复实测。
- 实际2GB Linux环境运行Web、分析、补丁流程，记录峰值、响应表现和限制；按结果调整配置。

验收：访客无法执行任务或读取内部数据；公开报告无测试secret/私有路径；撤回生效；恢复后数据和制品匹配。真实运行与样例明确区分，全部F01—F12逐项给出结论。容量不达标则收敛上下文或功能，不能虚报适配。

## 6. 后续按需立项

搜索发现、定时扫描、PR远端同步、流式进度、多模型或自动验证均不属于当前交付。安全执行需独立威胁模型、隔离验证和资源评估；不因增加一个按钮就允许宿主运行项目代码。Postgres/Redis/向量库/分布式队列无预定引入日期。

建议证据目录：evidence/M0/、M1/、M2/、M3/。每份记录日期、环境、版本、命令、真实结果与未执行项，不包含真实凭据。
