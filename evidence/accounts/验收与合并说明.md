# 账号注册与独立工作台验收

日期：2026-10-30（北京时间）。用户选择每人独立工作台、任务与数据隔离、各自配置模型密钥。

## 已实施

- 用户名/密码注册、登录、退出、修改密码；改密撤销全部设备会话。
- 原管理员继续使用原业务库，通过旧密码入口登录后自行绑定用户名；绑定后关闭免用户名登录。
- 每人独立业务 SQLite；会话注册表选择工作台，不信任客户端提供的用户归属。服务器单进程、全部工作台共用单执行槽。
- 每人配置 DeepSeek API Key 和 GitHub Token，AES-256-GCM 加密保存且不回显。新用户不继承服务端密钥。
- 原管理员查看账号列表、停用/启用普通账号；停用撤销会话、停止工作并隐藏其公开报告。
- 保留密码小眼睛按住显示交互。凭据更新不会自动调用模型。
- 更新发布包冒烟：实际加载编译后的账号网关，注册新账号、确认无继承密钥、私有数据为空、普通用户不能管理账号、退出后失效，禁止外部网络请求。

## 验证

- 类型检查、正式构建通过；全量 **101 项测试通过**。
- 账号测试覆盖用户名大小写、保留名、并发注册名额、所有会话撤销、管理员绑定、禁用账号、密文持久化、丢失主密钥拒绝启动。
- 跨账号测试覆盖原管理员任务拒绝访问、配置/模型凭据/诊断记录隔离、Origin/CSRF、全局执行槽及登录限流。
- 离线浏览器验证通过：注册、显示密码、保存个人密钥且输入清空、模型配置与夹具探测、第二用户隔离、修改密码及重新登录、手机无横向溢出、无页面脚本错误。
- 另行离线浏览器验证管理员绑定用户名后可登录，旧密码入口消失。
- 本地原服务启动前完成原数据库备份。账号网关上线后，只读核对原管理员仍有 **2 条任务**，已完成任务和审核包均保留，原有凭据仍可用。未替用户注册新账号、绑定真实管理员用户名或修改其密码。
- 本轮未发起真实模型调用、GitHub 扫描或公开发布。夹具探测不代表新增真实模型验收。

## 运维边界

新账号上限 20（含管理员），不是大规模多租户容量承诺。未提供邮件验证、短信、找回密码或 MFA。原单库备份命令不足以覆盖账号库、主密钥和所有工作台，完整操作见 `docs/账号与独立工作台.md`。原历史阶段证据不改写。
