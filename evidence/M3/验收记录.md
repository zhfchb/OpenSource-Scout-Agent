## 浏览器实测

Python Playwright 1.64.1 + 本机 Edge，无头、reduced-motion、1440px 桌面及 390px 移动端；Fastify 正式构建 + 真正临时 SQLite，模型/GitHub 使用明确标记的 FIXTURE，不产生真实调用费用。

`browser_m1.py`：任务创建/轮询/详情/用量/幂等/刷新/HTML 转义/移动端/退出通过。

`browser_m2.py`：计划修订和确认、单次生成、三类实际文件下载与包 SHA-256、人工审核和 MANUAL 记录、刷新、拒绝下载、鉴权通过。

`browser_m3.py`：游客空首页 → 管理员登录 → 夹具分析 → 编辑公开字段 → 预览脱敏 → 勾选确认 → 发布；独立无 Cookie 游客读取列表/详情，无法访问任务/运维。恶意 `<img onerror>` 保持纯文本，无 img 注入和 pageerror。编辑后确认失效，刷新保持发布状态；撤回后独立游客 404。移动端无横向溢出，过期记录清理和退出通过。

已查看最终游客首页、详情与移动端截图，均在本机忽略目录 `data/browser-evidence/M3/`，不是线上成果。样例明确标 FIXTURE，验收后撤回并关闭专用夹具服务；3107 仅保留无真实凭据的本地预览。
