# M4 模型诊断与主动连接测试

2026-10-29。本地实现与 FIXTURE 验证完成；真实付费模型分析/补丁闭环未执行。详见 [验收记录](../evidence/M4/验收记录.md)。

## 使用流程

1. 管理员进入“设置与限额”，填写模型标识和凭据环境变量名称。真实密钥只在服务端注入，不能填写到模型名称或文档里。
2. 保存设置。保存采用 revision 乐观锁；冲突时刷新页面再编辑。保存不触发供应商请求。
3. 查看“当前保存配置”：模型、引用存在性、最小请求预算。GitHub 凭据缺失仅提示匿名读取可能受限。本地检查只读取数据库和指定引用的存在性。
4. 自愿勾选费用确认，再点击“主动连接测试”。仅发送服务端固定短 JSON 提示；不含 Issue、源码或数据库内容。按钮可能发送一次计费请求，不自动重试。
5. 查看 FIXTURE/LIVE、配置版本、时间、状态、耗时、实际 Token 或未知预留。刷新可恢复最近 10 条持久记录。成功只证明此次连接和最小 JSON 校验通过，不代表分析或补丁准确。

未保存编辑禁用测试并将旧结果标为历史。只有成功记录的 revision、bootId 同时匹配当前服务才标当前成功；重启后旧成功记录仍保留，但不能代表新密钥可用。

## 限额和执行

| 项目 | 默认值 |
|---|---|
| UTC 日调用数 | 5 次，`MODEL_TEST_DAILY_CALLS` |
| UTC 日 Token | 10000，`MODEL_TEST_DAILY_TOKENS` |
| 最短发起间隔 | 60000ms，`MODEL_TEST_INTERVAL_MS` |
| 输出上限 | 64 Token |
| 响应读取上限 | 16KiB |
| 超时 | 已保存设置值与 30 秒的较小值 |
| 总历史条数 | 1000，达到后拒绝新增，不自动删除 |

修改服务端限额需更新环境配置并重启。UTC 日零点对应北京时间 08:00；页面显示本地可读的北京时间重置点。不显示未经账单核实的金额。

预算独立于业务任务：调用前以序列化固定请求 UTF-8 字节数 +128+64 保守预留，不是实际 Token。已知 usage 按实际结算；未知保留预留，跨日返回仍归原预留日。失败/取消不自动退款。

业务任务和探测共享执行槽。存在活动或排队任务时立即拒绝探测，不会等待后突然计费；探测期间新任务可入队。取消先写入状态和 attempt，再中止请求，执行槽待请求真正结束才释放。迟到 usage 可结算，迟到成功不能覆盖取消。

## 接口和恢复

- `GET /api/admin/settings` 返回 `settings` 与 `revision`；保存为 `PUT`，请求 `{settings, expectedRevision}`。旧平铺请求不再接受。
- `GET /api/admin/model-diagnostics` 无联网副作用。
- `POST /api/admin/model-tests`：`{requestKey, settingsRevision, acknowledgeCost:true}`。同 key 同参数返回原记录，不调用第二次；参数冲突返回 409。
- `GET /api/admin/model-tests/:id`：私有状态；`POST .../:id/cancel` 请求 `{expectedAttempt}`。
- 沿用管理员鉴权、Origin、CSRF、no-store 和严格 schema；不接受任意端点、密钥或自由 Prompt。

使用新增迁移 005，未修改 001–004。启动将遗留 RUNNING 探测标为 INTERRUPTED，未知用量保留，不重放。备份校验包含新表；新版 restore 验证源文件后只迁移目标副本，设置持久恢复 guard，至下个 UTC 日暂停新探测，重复重启不能清除。恢复前后费用以供应商账单为准。旧备份必须通过新版恢复工具处理。

错误显示固定机器码、关联 ID、步骤/结果和用量状态、下一步，不显示供应商原始响应或异常。DeepSeek 状态分类参考 [官方错误码](https://api-docs.deepseek.com/quick_start/error_codes/)（2026-10-29 核对）；402 只反映本次远端拒绝，不代表应用查询了账户实际余额。

旧任务保留不可变配置。替换同名环境变量中的密钥并重启后，可在原状态和预算允许时手动重试分析；改变模型、引用、超时或限额只影响新任务，新建任务可能重复工作并计费。已使用的补丁计划仍需保存并确认新版本，不重放旧请求。

本阶段不实现 M5 自动发现、不写入 GitHub、不执行目标代码、不自动发布报告。无有效凭据时连接测试和业务闭环的真实验收保持 NOT_RUN。
