# M1：手动公开 Issue 分析

本页描述既有 M1 手动入口及该阶段能力，不表示整个项目仅支持手动方向。v2 已新增 [M5 自动发现设计](M5自动发现设计.md)（本地已实现），后续从候选人工选择并完成状态复核后接入此分析流程；发现本身不读取源码或调用深入分析模型。M1 的原始验收事实保留。

## 使用流程

1. 配置私有环境文件并启动正式构建，详见部署运维文档。默认只支持 DeepSeek，端点固定为 `https://api.deepseek.com/chat/completions`，不接受任务或网页传入任意服务地址。
2. 在私有环境文件中配置 `MODEL_API_KEY`；公开 GitHub 访问可不设 token，若设 `GITHUB_TOKEN` 应只授予所需只读权限。密钥不要发到聊天、写入仓库或页面输入框。变更环境后重启应用才能生效。
3. 管理员登录设置页，填写账号可用的 DeepSeek 模型标识；保持密钥引用为环境变量名称。新任务保存这次设置快照；旧任务重试继续使用原快照，不读取新的限额。
4. 任务页输入 GitHub 仓库或 Issue HTTPS 链接，点击解析。仓库入口仅查看最多两页、每页 20 条开放记录，过滤 PR 后可选数量可能更少。直接 Issue 链接不受列表范围限制，创建时仍会验证公开性和 Issue 类型。
5. 选择 Issue 后点击开始分析。页面轮询状态，单进程同一时刻仅运行一个任务，最多排队 10 个任务。
6. 查看来源 Commit、实际提供给模型的文件、数据缺口、可核查引文、疑点和计划建议。当前结束状态为 `WAITING_CONFIRMATION`，表示等待人工审查；M1 没有确认按钮、补丁生成和公开报告。

## 范围与真实性

- 只使用 GitHub REST GET；没有 fork、push、PR、评论写入工具。仓库不克隆到磁盘，不安装依赖、执行 hooks、编译或测试目标项目。
- 固定默认分支查询时对应的 Commit；Issue 与源码在各自读取时获取，并非 GitHub 提供的跨资源原子快照。重试有已保存快照时复用 Commit；源步骤尚未成功保存时重试会重新获取并选择 Commit。
- 目录树响应最大 1MB，GitHub 截断会记录缺口；超过此上限则失败，不继续无界分页。源码按 Issue 提及路径、README、路径排序选取有限候选，屏蔽点目录、敏感路径、二进制、依赖/构建产物。不是完整代码检索，不能保证找到了根因。
- 单文件、总字节、文件数、模型输入和输出都有限额；上下文按 UTF-8 字节保守估计预留，优先保留能放入上下文的完整文件。被省略或截断的内容写入缺口。
- JSON 输出有运行时字段/类型/枚举/长度检查；引文必须是 Issue 或实际提供文件的精确子串，链接由服务端生成。它只验证引文存在，不证明推断正确。无引文时页面明确提示依据不足。
- 模型返回的文字直接以文本渲染，不能执行 HTML。不保存隐藏推理。API 错误只显示固定错误代码，不持久化原始远端错误或密钥；供应商回显当前凭据时拒绝保存结果。

## 预算、取消与恢复

每次模型调用前持久预留输入上界 + 2048 输出 Token，同时占用一次调用。预算按同一任务的全部重试累计；用量缺失、超时或不确定失败保留预留，并标 `UNKNOWN`，不能记为零。收到可用 usage 时保存实际总 Token，即使随后输出校验失败也计入实际调用。模型不会自动重试；只读 GitHub 短暂网络错误最多重试一次，不重试权限/限流错误。

取消会先更新任务状态和 attempt，再中止网络请求；迟到结果不能覆盖状态和分析，账单用量仍可落在原调用记录中。下一任务等待旧请求结束/中止，确保单活动任务。等待审查不占住执行器。重试需要匹配当前 attempt，重复请求不会重复入队；创建请求同一 requestKey 保持幂等，网络异常后页面保留 key 便于重试。

重启时遗留 `RUNNING` 和 `QUEUED` 都标 `INTERRUPTED`，未完成用量预留改为 `UNKNOWN`；不自动重放调用，必须手动重试。已经保存的分析和来源不丢弃。达到累计预算后不会继续调用；如确需重新分析，明确创建一个新任务并承担新调用费用。

## 备份与验证

来源快照、分析、步骤和用量均在 SQLite 中，M1 没有新增外部制品文件，一致性 backup API 覆盖当前数据。仍只支持一个应用实例，不能同时启动两个进程指向同一数据库。

常规检查：`npm run typecheck`、`npm run build`、`npm test`。浏览器夹具：构建后运行 `node tests/start-m1-smoke.mjs`，使用 Python Playwright + Edge 运行 `python tests/browser_m1.py`。3108 服务和页面明确标 `FIXTURE`，没有真实外部调用；仅用于开发验收。

可选真实 GitHub 只读检查：`node tests/live-github.mjs`，结果写入忽略目录 `data/M1/live-github.json`。此脚本不会调用模型或执行目标代码。完整真实分析仍需要有效模型凭据；详见 M1 验收记录，不能把夹具输出当作真实分析成果。
