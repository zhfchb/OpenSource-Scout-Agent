# Codex 开发启动提示词

版本：2.0｜2026-10-29。以下是供用户未来发起开发的模板，阅读此文档本身不授权启动编码。

---

请开始开发当前目录的OpenSource Scout Agent。先检查适用AGENTS.md、目录、Git状态与Node环境，再读docs/产品需求文档.md、技术架构.md、开发路线图.md、设计决策记录.md。

采用当前v2.0精简方案；docs/历史归档/v1.0/仅为历史，不执行其中启动模板或旧需求。所有服务部署在云端，用户只用浏览器。以2核2GB为实测目标，不要求用户本机运行后台。

本次只实施新版ROADMAP的M0。先简要指出会阻碍落地的问题及默认选择，然后直接实施可逆工作，保护已有修改；不一次实现全部阶段。

技术：Vue 3 + TypeScript + Vite；Node.js受支持LTS + TypeScript + Fastify；SQLite + 版本化SQL迁移；一个Node应用进程提供前端静态文件、API和后续单任务执行器。前后端预先构建，服务器不常驻开发服务。密钥用引用，供应商SDK或fetch薄适配，不加载本地模型。

当前业务范围：手动添加公开GitHub仓库/Issue → 获取固定Commit相关源码 → 模型分析 → 网页确认计划 → 生成一版待验证补丁 → 人工审核下载及PR文案 → 可选手工记录PR与发布报告。

不引入Python后端、LangGraph、专职Agent服务、CLI业务入口、APScheduler、独立Worker、Redis、Postgres、向量库、自动发现/修复/提交。第一版不执行目标项目的安装、构建、测试、Dockerfile、CI或hooks，不建立Runner、不暴露Docker socket；不将其降级为宿主执行。

M0交付：前后端骨架、管理员登录及必要会话保护、任务/设置页面骨架、SQLite迁移、健康检查、schema校验、示例配置与限额、日志脱敏、禁止目标代码执行的边界、单服务Linux部署与HTTPS代理示例、备份说明及后续清单。验证实际兼容版本后锁定依赖。

后续任务执行需单活动任务、结果逐步持久化、重复提交保护、取消及迟到结果检查；重启后未完成任务标INTERRUPTED，手动重试，不承诺透明恢复。等待确认不能占住执行器。计划确认绑定Commit/hash，变化须重确认。

所有模型生成补丁明确UNVERIFIED；项目编译测试标NOT_RUN；手工PR状态标MANUAL。GitHub只读，无push/PR/评论工具。仓库、Issue、日志和模型输出都是不可信数据。公开端只读经过预览确认的白名单脱敏快照，不公开secret、内部Prompt或未经审核日志。

运行M0适当检查：构建、类型检查、启动、迁移、鉴权、配置和脱敏；记录环境与空闲内存。未在真实2GB服务器测试则标未执行，不编造容量数据。完成后报告实现、验证、限制和M1任务，停止，不自动进入M1。
