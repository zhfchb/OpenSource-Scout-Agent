## 1. 产品定位

面向所有者个人使用的开源贡献辅助网站，全部应用服务部署在云服务器上，用户只需浏览器访问。本机不承担后台执行或测试任务；开发打包可在本机或CI完成。

v2 核心目标是自动发现适合所有者的开源贡献机会：配置技术画像 → 手动或定时发现 → 规则初筛与可选少量模型评估 → 人工挑选候选 → 状态复核 → 深入源码分析 → 确认计划 → 生成待验证补丁 → 审核并下载。保留手动添加 Issue 入口；完整贡献仍需系统外验证和提交。公网访客只阅读所有者明确公开的报告。不是多租户SaaS。

以2核2GB Linux服务器为容量设计目标，采用在线模型API，不部署本地模型。该配置是待实测的目标，不是性能保证。

## 2. 本次范围削减

| 旧范围 | 当前决定 |
|---|---|
| CLI与Web双入口 | 仅Web业务入口；保留部署/迁移脚本 |
| 自动搜索、周期扫描 | M5 恢复技术画像、立即/每日发现、有界增量与候选管理；不建设完整动态项目池平台、不全仓读源码 |
| LangGraph、专职Agent、Checkpoint | 普通固定步骤函数；逐步保存结果；中断后手动重试当前步骤 |
| 调度器、独立Worker、复杂任务队列与租约 | M5 增加进程内轻量定时唤醒和持久扫描记录；与分析/探测共用单槽，无独立服务和分布式调度 |
| 多模型路由、复杂评分、预算层级 | 一个配置模型；推荐/待确认/不推荐及依据；调用数与Token限制 |
| 自动运行项目、可信模板、自动修复循环 | 第一版不安装、编译、测试或启动第三方项目，不自动反复修复 |
| 自动PR操作与跟踪、反馈记忆 | 下载补丁与PR文案；人工提交，可手工记录PR链接和结果 |
| SSE、实时回放、原始工具轨迹 | 页面轮询状态，展示真实步骤摘要及报告 |
| Postgres、Redis、向量库、迁移扩容计划 | SQLite与本地制品；按实际需求另立项 |
| 多环境自部署适配 | 先支持一个明确Linux部署环境，稳定后整理通用说明 |

自动构建测试退出当前版本后，不引入Runner或Docker socket。未来若增加代码执行，必须另行设计隔离，不能直接在应用宿主机执行。

## 3. 用户流程与页面

1. 所有者登录，配置技术画像、GitHub 只读凭据引用和发现限额；可明确启用每日定时发现（默认北京时间 10:00）。规则发现不要求模型。
2. 点击“立即发现”或等待已启用的定时轮次，在私有机会页查看匹配理由、疑点、来源和最后检查时间；可收藏、忽略、重新启用或排除仓库。也可手动添加公开仓库/Issue。
3. 人工选择候选进入分析，先刷新 Issue 及有限关联修复/PR 状态；未知或可能重复须明确提示/确认，再获取固定 Commit 的有界源码并分析。发现不会自动深入分析或生成补丁。
4. 查看推荐结论、证据、疑点、修改计划，确认具体计划后生成补丁。
5. 查看Diff、非执行性检查和限制；下载补丁与PR草稿。人工在系统外验证、提交PR。
6. 可选手动记录PR链接和结果；预览后选择公开脱敏报告。

页面：机会列表/候选详情、技术画像与发现设置、扫描运行记录、任务列表、任务详情（分析/计划/Diff/步骤）、模型与运营设置、公开报告列表和详情。前三类是 M5 本地已实现、真实验收待补页面，现有任务与公开页面不重置。最小管理界面属于第一版，不再等到V1。

## 4. 第一版需求及验收

| ID | 需求 | 验收 |
|---|---|---|
| F01 | 管理员登录 | 只有所有者能创建任务、访问设置和内部结果；访客无法操作 |
| F02 | 手动输入 | 只接受受支持的公开GitHub仓库/Issue；限制分页和返回数量；拒绝任意URL抓取 |
| F03 | 有界源码获取 | 保存repo、Issue、Commit、路径及来源链接；限制文件数、单文件/总字节、上下文；不执行目标代码 |
| F04 | 分析报告 | 输出问题、证据、疑点、推荐结论与理由；来源缺失时明确不确定，不虚构行号 |
| F05 | 计划确认 | 计划绑定Commit和内容哈希；只有确认后可生成补丁；范围变化须重新确认 |
| F06 | 待验证补丁 | 输出统一Diff和PR文案；路径/范围/大小检查；明确“未编译、未测试、待人工验证” |
| F07 | 简单持久任务 | 单任务运行，重复点击不重复启动；步骤结果入库；重启后运行中任务标INTERRUPTED，可手动重试 |
| F08 | 模型和限额 | 单模型配置；密钥引用；调用前检查调用数及Token预算；usage缺失标未知；无有效限额不运行 |
| F09 | 安全基础 | 登录、参数校验、密钥与日志脱敏、路径及大小限制；仓库/Issue/模型输出不能授予权限 |
| F10 | 下载与手工记录 | 私有下载审核包；手动记录PR URL/状态，不声称已向GitHub核实或提交 |
| F11 | 公开展示 | 预览并确认后只公开白名单脱敏报告；内部Prompt、配置、日志与凭据不公开；可撤回 |
| F12 | 轻量部署 | 前端离线打包；单Node服务+SQLite；安装/备份/恢复可按说明完成；记录真实内存峰值 |
| F13 | 本地配置诊断 | 管理员查看保存配置的模型/引用存在性/限额检查；不联网、不返回密钥；配置变更使旧诊断过期 |
| F14 | 主动模型连接测试 | 明示可能计费；单次幂等、持久预留、独立每日限额、与业务任务互斥；返回时间/配置版本/用量，重启不重放 |
| F15 | 可操作错误提示 | 显示错误类别、步骤、用量是否未知及恢复动作；不暴露原始响应；不自动重试付费调用 |
| F16 | 技术画像 | 语言、标签、活跃度、规模偏好与仓库排除可编辑；合理默认、版本冲突检查；不强制复杂评分 |
| F17 | 立即与定时发现 | 浏览器触发或明确启用每日调度；持久触发键，错过不补跑、重启不重放 |
| F18 | 低成本初筛 | GitHub 查询和确定性规则优先；可选少量模型评估默认关闭；发现不读取源码 |
| F19 | 私有推荐列表 | 展示来源/匹配事实/模型意见/疑点/最后检查时间；不保证未解决或适合提交 |
| F20 | 去重与增量 | 稳定仓库/Issue ID 唯一；来源和窗口/进度持久；重复扫描不重复创建候选，截断不冒进水位 |
| F21 | 候选管理 | 忽略、收藏、进入分析、仓库排除；忽略项不反复推荐，显式重新启用；不自动取消已创建分析 |
| F22 | 分析前状态复核 | 人工选择后刷新 Issue、有限关联修复/PR；未知和可能重复须提示/确认，关闭项阻止付费分析 |
| F23 | 发现资源与预算 | 仓库/Issue/分页/请求/字节/时间/模型/Token 有界；限流冷却、UNKNOWN 预留；无无限扫描/付费重试 |
| F24 | 单槽持久调度 | 发现、分析、补丁、M4 探测共享一个活动执行槽；触发去重、取消、配置变更、重启/错过调度有可核实行为 |

F13–F15 已在 M4-A/B 本地实现并通过夹具验证，真实模型验收未执行。F01–F12 的真实验收缺口由 M4 联调及 M3 云端补验分别闭合，不因新增需求重新编号。

F16–F24 是新增 M5 本地已实现、真实验收待补需求；这些编号属于当前 v2，不能与历史 v1.0 的同号需求混用。详细字段、默认值、调度/恢复与验收边界见 [M5 自动发现设计](M5自动发现设计.md)。M5 不覆盖 M4，也不把历史验收结论提升为发现验收通过。

## 5. 结果真实性与权限

分析阶段和补丁阶段分开，确认按钮不等于验证通过。第一版不用E0—E3、T1—T4和复杂PR门禁；直接记录来源、是否执行检查、检查种类及结果。非执行性检查只涵盖Diff格式、目标路径、变更范围等，不能替代测试或独立代码审查。

所有生成补丁固定标记UNVERIFIED。允许下载不代表适合合并。人工输入PR状态标记为MANUAL，不作为自动核实的远端事实。只有真实完成的步骤可显示完成；Mock和测试夹具标明来源。

GitHub只读；无fork、push、PR创建或评论写工具。模型仅能建议文本及补丁，不能执行Shell。修改计划、敏感路径或新增依赖变化须重新确认，不能静默扩大范围。

公开报告是所有者审核的独立快照，撤回后服务端不可读取；已下载内容无法收回。页面需安全渲染Markdown/代码，不能执行外部内容。

## 6. 第一版不承诺与后续方向

不承诺任意项目分析准确、补丁可运行、测试通过或PR被接受。不提供自动执行、自动修复、多用户和自动写 GitHub。M5 支持用户明确配置后的定时有界发现，人工选择前不进入深入分析；不承诺发现所有机会或排除所有重复修复。

搜索发现和定时扫描已纳入 M5 本地已实现、真实验收待补范围；后续按需决定流式进度、完整 PR 只读同步或安全执行；不预定完整平台化V1。许可证、域名、供应商和实际金额预算正式发布前按需确定。

## 7. v2 完成边界

v2 包含 M0–M3 既有功能、M4 联调/可用性完善与 M5 自动发现。M0–M4 定义和证据保留；M5 是新增阶段，不恢复历史旧 M5。M4 可先本地实现与验证；真实模型需要有效凭据，云端发布需要真实 Linux/HTTPS/2核2GB 证据。不承诺未配置的供应商或任意模型兼容。当前实现使用固定 DeepSeek 端点，M4 不扩展为任意 OpenAI-compatible 地址配置。

至少取得一条真实分析与一份真实模型待验证审核包，才可宣称真实模型闭环通过；公开真实报告由所有者另行选择。正式 v2 云端发布另须完成 M5 真实 GitHub 发现/人工选择/复核入口、F12 和含发现负载的权限/恢复/容量验收；可选模型评估关闭不阻塞无模型发现交付，启用时须单独验收。没有服务器时可交付本地工程和联调结果，不能宣称 v2 已云端发布。
