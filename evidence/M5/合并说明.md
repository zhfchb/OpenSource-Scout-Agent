# PR 标题

实现 M5：轻量自动发现、候选管理与分析前复核

# PR 描述

新增技术画像和只读 GitHub 发现入口，按规则生成私有候选，支持收藏、忽略、仓库排除及每日定时。候选经人工选择、有限状态复核与风险/费用确认后，才接入现有深入分析，不自动生成分析或补丁。

- 统一持久 FIFO 与执行槽，覆盖发现/复核/分析/补丁及 M4 探测互斥；加入预算、限流冷却、增量水位、取消和重启保护。
- 可选少量模型评估默认关闭，持久 dispatch/用量防止跨轮自动重复付费。
- 新增迁移 006，备份包含新表；恢复关闭定时和评估，并持久保留当日付费禁用期。
- 新增浅蓝机会发现页、操作说明、浏览器与真实 GitHub 证据。

验证：类型检查、正式构建、78 项测试、M1–M5 浏览器回归通过。真实立即发现和人工来源复核有结果；正常整点调度已触发但受 GitHub 限流，成功候选与最终同窗口去重仍待补验。真实模型及 Linux/HTTPS/2核2GB 未执行，未声称完整 v2 发布通过。
