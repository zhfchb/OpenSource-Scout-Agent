## 2. 当前实施状态

以下根据仓库现存验收记录整理，本次文档工作未重跑应用测试，也未复核线上服务或远程 CI。

| 阶段 | 本地证据 | 尚缺的验收 |
|---|---|---|
| M0 | 工程、鉴权、迁移、部署示例；见 [记录](../evidence/M0/验收记录.md) | 真实 Linux/HTTPS 与目标硬件 |
| M1 | 22 项测试和浏览器夹具；曾成功读取真实 GitHub 来源 | 有效模型分析；最终源码校验版本的真实 GitHub 复核 |
| M2 | 34 项测试、确认、静态 Diff 检查及下载夹具 | 真实模型生成审核包 |
| M3 | 43 项测试、公开快照、配额、备份恢复及浏览器夹具 | Linux、HTTPS、2核2GB、真实模型闭环 |
| M4 | 已有设计，尚无对应代码/验收记录 | 功能实现、回归、真实模型与失败验收全部待执行 |
| M5 | 本次新增自动发现设计；当前代码未实现发现/画像/调度 | 夹具、浏览器、真实 GitHub、可选模型及新增容量验证均未执行 |

M4 负责补齐跨 M1/M2/M3 的真实使用证据，不追溯把原阶段写成全部通过。云端容量继续属于 M3 的未完成验收。M4 本地通过、M5 发现通过、v2 云端发布通过分别记录；发现的真实来源不替代真实模型审核包，M4 通过也不代表 M5 已实现。

## 3. 历史设计的取舍

| 历史能力/原则 | v2 处理 |
|---|---|
| 人工确认、证据来源、预算、失败可解释 | 保留；以 Commit/hash、精确引文、UNKNOWN 用量落实 |
| 公开真实成果、发布批准与撤回 | 保留；发布独立白名单快照 |
| Worktree、沙箱、分级测试、有限自动修复 | 当前不执行第三方代码，不建设执行面；补丁固定 UNVERIFIED |
| LangGraph、Checkpoint、独立 Scheduler、多 Worker | 普通函数、SQLite、单执行器；M5 恢复同进程轻量定时与持久记录 |
| 技术画像、自动搜索、增量、周期发现 | 按新 M5 恢复有界版本；规则优先、模型可选、人工选择 |
| 复杂评分、全仓主动探索、经验记忆、完整动态项目池 | 暂缓，无排期承诺 |
| CLI、完整后台后置、SSE | 浏览器管理提前实现；轮询；脚本仅用于部署和维护 |
| 多模型、远端 PR 同步与 GitHub 写入 | 不纳入 v2；M4 仍单供应商/单模型、PR 来源 MANUAL |

## 4. 维护规则

新增功能先更新 PRD/阶段/验收；接口细节写专项设计；实施后更新使用说明、实际证据和本页状态。已应用 SQL 迁移与历史验收不覆盖。不得在文档填入真实密钥、密码、私有数据或带访问权限的链接。

当前设计修订为 2.2，仍是产品 v2，不是已发布软件版本。本轮恢复自动发现的最新依据是 ADR-037；早期文档里的“不自动发现”仅说明当时削减决定，不能作为当前 M5 的禁止项。MANIFEST.json 记录当前文档实际字节数与 SHA-256，不代表功能验收或软件制品签名。
