# OpenSource Scout Agent 产品需求文档

版本：2.0｜日期：2026-10-29｜状态：待实施的精简设计基线。

配套文档：[架构](技术架构.md) · [路线图](开发路线图.md) · [决策](设计决策记录.md) · [启动提示词](开发启动提示词.md)。旧版五份文档保留在 历史归档/v1.0/，仅供历史参考，不作为当前实施要求。

## 1. 产品定位

面向所有者个人使用的开源贡献辅助网站，全部应用服务部署在云服务器上，用户只需浏览器访问。本机不承担后台执行或测试任务；开发打包可在本机或CI完成。

第一版目标是：添加GitHub Issue → 获取相关源码 → 分析问题 → 确认计划 → 生成待验证补丁 → 审核并下载补丁和PR文案。公网访客只阅读所有者明确公开的报告。不是多租户SaaS。

以2核2GB Linux服务器为容量设计目标，采用在线模型API，不部署本地模型。该配置是待实测的目标，不是性能保证。

## 2. 本次范围削减

| 旧范围 | 当前决定 |
|---|---|
| CLI与Web双入口 | 仅Web业务入口；保留部署/迁移脚本 |
| 动态项目池、自动搜索、周期扫描 | 手动添加公开仓库或Issue链接；仓库入口先列出有限数量Issue供选择，不全仓主动找问题 |
| LangGraph、专职Agent、Checkpoint | 普通固定步骤函数；逐步保存结果；中断后手动重试当前步骤 |
| 调度器、独立Worker、复杂任务队列与租约 | 一个Node进程，SQLite任务表，单任务执行；无独立调度/Worker服务 |
| 多模型路由、复杂评分、预算层级 | 一个配置模型；推荐/待确认/不推荐及依据；调用数与Token限制 |
| 自动运行项目、可信模板、自动修复循环 | 第一版不安装、编译、测试或启动第三方项目，不自动反复修复 |
| 自动PR操作与跟踪、反馈记忆 | 下载补丁与PR文案；人工提交，可手工记录PR链接和结果 |
| SSE、实时回放、原始工具轨迹 | 页面轮询状态，展示真实步骤摘要及报告 |
| Postgres、Redis、向量库、迁移扩容计划 | SQLite与本地制品；按实际需求另立项 |
| 多环境自部署适配 | 先支持一个明确Linux部署环境，稳定后整理通用说明 |

自动构建测试退出当前版本后，不引入Runner或Docker socket。未来若增加代码执行，必须另行设计隔离，不能直接在应用宿主机执行。

## 3. 用户流程与页面

1. 所有者登录，配置GitHub只读凭据引用、模型和限额。
2. 添加公开GitHub仓库或Issue URL；仓库入口选择一个Issue。
3. 点击分析：获取Issue和固定Commit下的相关文本源码，生成有出处的分析。
4. 查看推荐结论、证据、疑点、修改计划，确认具体计划后生成补丁。
5. 查看Diff、非执行性检查和限制；下载补丁与PR草稿。人工在系统外验证、提交PR。
6. 可选手动记录PR链接和结果；预览后选择公开脱敏报告。

页面：任务列表、任务详情（分析/计划/Diff/步骤）、设置、公开报告列表和详情。最小管理界面属于第一版，不再等到V1。

## 4. 第一版需求及验收

| ID | 需求 | 验收 |
|---|---|---|
| F01 | 管理员登录 | 只有所有者能创建任务、访问设置和内部结果；访客无法操作 |
| F02 | 手动输入 | 只接受受支持的公开GitHub仓库/Issue；限制分页和返回数量；拒绝任意URL抓取 |
| F03 | 有界源码获取 | 保存repo、Issue、Commit、路径及来源链接；限制文件数、单文件/总字节、上下文；不执行目标代码 |
| F04 | 分析报告 | 输出问题、证据、疑点、推荐结论与理由；来源缺失时明确不确定，不虚构行号 |
| F05 | 计划确认 | 计划绑定Commit和内容哈希；只有确认后可生成补丁；范围变化须重新确认 |
| F06 | 待验证补丁 | 输出统一Diff和PR文案；路径/范围/大小检查；明确“未编译、未测试、待人工验证” |
| F07 | 简单持久任务 | 单任务运行，重复点击不重复启动；步骤结果入库；重启后运行中任务标INTERRUPTED，可手动重试 |
| F08 | 模型和限额 | 单模型配置；密钥引用；调用前检查调用数及Token预算；usage缺失标未知；无有效限额不运行 |
| F09 | 安全基础 | 登录、参数校验、密钥与日志脱敏、路径及大小限制；仓库/Issue/模型输出不能授予权限 |
| F10 | 下载与手工记录 | 私有下载审核包；手动记录PR URL/状态，不声称已向GitHub核实或提交 |
| F11 | 公开展示 | 预览并确认后只公开白名单脱敏报告；内部Prompt、配置、日志与凭据不公开；可撤回 |
| F12 | 轻量部署 | 前端离线打包；单Node服务+SQLite；安装/备份/恢复可按说明完成；记录真实内存峰值 |

## 5. 结果真实性与权限

分析阶段和补丁阶段分开，确认按钮不等于验证通过。第一版不用E0—E3、T1—T4和复杂PR门禁；直接记录来源、是否执行检查、检查种类及结果。非执行性检查只涵盖Diff格式、目标路径、变更范围等，不能替代测试或独立代码审查。

所有生成补丁固定标记UNVERIFIED。允许下载不代表适合合并。人工输入PR状态标记为MANUAL，不作为自动核实的远端事实。只有真实完成的步骤可显示完成；Mock和测试夹具标明来源。

GitHub只读；无fork、push、PR创建或评论写工具。模型仅能建议文本及补丁，不能执行Shell。修改计划、敏感路径或新增依赖变化须重新确认，不能静默扩大范围。

公开报告是所有者审核的独立快照，撤回后服务端不可读取；已下载内容无法收回。页面需安全渲染Markdown/代码，不能执行外部内容。

## 6. 第一版不承诺与后续方向

不承诺任意项目分析准确、补丁可运行、测试通过或PR被接受。不提供自动执行、自动修复、无人值守持续发现、多用户和自动写GitHub。

后续以真实使用需求决定是否增加搜索发现、定时扫描、流式进度、PR只读同步或安全执行；不预定完整平台化V1。许可证、域名、供应商和实际金额预算正式发布前按需确定。
